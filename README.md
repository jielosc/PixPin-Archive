# PixPin-Archive

这是一个专门用于存档 **PixPin** 历史版本的仓库。PixPin 是一款功能强大的截图、贴图、OCR 及长截图工具。

## 📥 下载中心 (Releases)

所有的安装包都存放在本仓库的 **[Releases](https://github.com/your-username/PixPin-Archive/releases)** 页面。

| 版本 | 文件名 | 说明 |
| :--- | :--- | :--- |
| 最新版 | `PixPin_setup_x.x.x.exe` | 见 Release 附件 |
| 历史版 | `PixPin_setup_x.x.x.exe` | 按标签查看 |

## 🔗 官方资源

* **官方网站**: [https://pixpin.cn/](https://pixpin.cn/)
* **官方文档**: [https://pixpin.cn/docs/](https://pixpin.cn/docs/)

## 🛠 存档说明

1. **版本来源**: 存档文件均来源于 PixPin 官方发布渠道。
2. **为何存档**: 为了防止官方版本迭代后旧版功能变更或链接失效，方便大家找回习惯的历史版本。
3. **免责声明**: 本仓库仅作个人备份与存档用途，版权归 PixPin 官方所有。如果官方认为此类存档不妥，请联系删除。
